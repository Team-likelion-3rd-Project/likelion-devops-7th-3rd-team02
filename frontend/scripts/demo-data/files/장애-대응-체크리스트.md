# 장애 대응 체크리스트

1. 알림 확인: DevFlow 사이드바 전체 장애 배지와 모니터링의 장애 목록을 본다.
2. 확인 처리: 장애를 "확인"으로 바꿔 다른 팀원이 중복으로 대응하지 않게 한다.
3. 담당자 지정: 원인을 볼 사람을 정한다.
4. 원인 파악: 모니터링의 Pod 상태, 재시작 횟수, 오류율, p95 응답 시간을 본다.
5. 복구: 필요하면 Argo CD로 이전 리비전으로 되돌린다 (배포-롤백-절차.md).
6. 확인: 알림이 풀리고 30분이 지나면 확인한 장애는 자동으로 해결된다. 먼저 닫아야 하면 "해결"을 누른다.
7. 기록: 원인과 조치를 업무 설명이나 회고 안건에 남긴다.
